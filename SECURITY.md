# Security policy

## Reporting a problem

Please **don't open a public issue** for security problems. Report them privately instead:

1. Go to the repository's **Security** tab.
2. Choose **Report a vulnerability** (GitHub private vulnerability reporting).

Include what you found, how to reproduce it, and which version of Lotus you used. You should
hear back within a few days. Please give a reasonable time to fix it before sharing details.

## What counts

For example:

- A way to get an update installed that wasn't signed with the project's updater key.
- Lotus writing to the game, sending it input, or reading more than it says it does (see the
  README's FAQ).
- Lotus sending a player's data anywhere it shouldn't.
- A downloaded file (item data, images, prices) being able to run code or write outside Lotus's
  data folders.

## Supported versions

Only the latest release gets fixes. Lotus updates itself, so a fix reaches everyone once it's
published.
